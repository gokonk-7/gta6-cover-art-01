Vice Cover Studio — offline multi-panel GTA-poster-style cover maker. Upload a photo, pick a layout (Triptych, Comic, Hero+Duo, Quad) and a grade (Sunset, Neon, Golden Hour, Noir), then export a 1080×1080, 1080×1350, or 1920×1080 cover PNG. All art is drawn procedurally on canvas; no Rockstar assets, logos, or fonts.

## Run it

```sh
node serve.ts
```

Open http://localhost:8123 in your browser.

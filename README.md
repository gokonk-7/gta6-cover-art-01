**Vice Cover Studio** turns any photo and caption into GTA 6 poster-style cover art: a multi-panel cover (Triptych, Comic, Hero + Duo, or Quad) over a procedural Vice City sunset — striped sun, skyline, palms, neon grid — with bold Anton lettering and four colour grades (Sunset, Neon, Golden Hour, Noir). Every panel takes its own photo (upload your own or use the bundled samples), each with drag-to-pan positioning and zoom, and the cover exports as a PNG in 1080×1080, 1080×1350, or 1920×1080. The app is plain static files under `app/` — it runs fully offline in a desktop browser, photos never leave your machine, and it uses no Rockstar logos, artwork, or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick a layout and grade, drop in your photos, edit the title, and save a PNG.
